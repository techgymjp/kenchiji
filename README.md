# 県知事になろう

ドラクエ風に県内を歩きまわって、17日間の知事選挙を戦い抜くブラウザゲームです。
投票日の夜は開票速報が流れ、だれかに「当選確実」が出たらゲーム終了です。

## 遊び方

Web 版はビルド不要の静的サイトです。`index.html` をブラウザで開くか、ローカルサーバーで配信してください。

```sh
npx http-server -p 8080 .
# → http://localhost:8080/
```


| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | 矢印キー / WASD | 十字ボタン |
| はなす・しらべる・決定 | Z / Enter / Space | A |
| メニュー・キャンセル | X / Esc | B |

## 表示言語（日本語 / English）

端末やブラウザの言語が日本語なら日本語、それ以外なら英語で表示します（英語版のタイトルは「Run for Governor!」）。タイトル画面の「🌐 English / 🌐 日本語」でいつでも切り替えられ、選んだ言語は次回も使われます。

- ゲーム中の文章は日本語のままコードに書き、英語は `js/i18n-en.js` の翻訳表（日本語の文 → 英語の文）から引きます。数や名前が入る文は `tr('聴衆は {n}人ほど あつまっている。', { n })` のように `{名前}` の形で書きます（`{N}` はプレイヤー名）。
- タイトル画面などの固定の文言と、プライバシーポリシーの URL（英語は https://techgym.jp/privacy-policy-en/ ）は `js/i18n.js` にあります。
- 文章を追加・変更したら `node scripts/check-i18n.js` を実行してください。英語の訳がない文と、`{}` の食い違いを一覧にします。
- Android のアプリ名も、端末が英語なら「Run for Governor!」になります（`android/app/src/main/res/values-en/strings.xml`）。

## ゲームの流れ

- **選挙運動（1〜17日目）**：毎日 8:00〜20:00 に活動できます。1歩で1分経過。20時になると1日が終わり、夜のニュースと情勢が届きます。
- **投票日（18日目）**：開票速報。得票差が大きければ 20時ちょうどに「ゼロ打ち」で当確、接戦なら開票が進むまで決まりません。

### やれること

- **演説台**（各地区に1つ）：6つのテーマから選んで演説。地区ごとに響くテーマが違います（農村なら農林水産、工業団地なら雇用など）。
- **ポスター掲示板**（県内24か所）：貼ると知名度と地域の支持が上がります。全部貼るとボーナスがあります。
- **団体まわり**：農協・漁協・商工会議所・医師会・労組・観光協会・建設業協会。あいさつで出される質問に答えて信頼度を上げ、推薦をもらうと現職の組織票を切り崩せます。
- **施設**：温泉・病院・喫茶店で体力回復、新聞広告やテレビCM、工場の門前あいさつ（朝）、保育園（夕方のお迎え時間）など。
- **握手**：街の人に話しかけると握手（1人1日1回）。
- **選挙カー**：メニューの「いどう」で各地区へ移動（30分）。
- **予定イベント**：農業者集会・朝市・公開討論会・温泉まつり・テレビ討論会・学園祭・最終日の「最後のお願い」。

### 日常のイベント（ランダムに発生）

歩いていると、いろいろな出来事に出くわします。選んだ行動の結果が**数日後に**返ってくることもあります。

- おばあさんの荷物を運ぶ → 翌朝、商工会議所の会頭が訪ねてくる（実は会頭の母だった）
- 喧嘩の仲裁 → 若者たちがポスター貼りを手伝ってくれる
- 具合の悪い女性に肩を貸す → 週刊誌に「深夜の密会」と撮られる…（対応しだいで逆転も）
- 現金の入った封筒を断る → 実はテレビ局の抜き打ち企画だった
- 白いスーツの男と記念写真 → 暴力団幹部とのツーショットとして報道される
- 「世界平和の署名」 → あやしい団体の会報に名前が載る
- 転んだおじいさんを救護 → 元農協組合長で、農協とのパイプができる
- ずぶ濡れ演説、突撃YouTuber、ひったくり、怪文書、人気芸人の応援、料亭への招待、フォロワー購入の誘い……ほか多数

善いことに見えて裏目に出るもの、断ると得をするものが混ざっています。神社でお参りすると、その日は悪い縁に巻きこまれにくくなります。

## BGM

初代ドラクエのようなファミコン風の電子音（矩形波2音＋三角波ベース）を Web Audio で鳴らしています。音源ファイルは使っておらず、曲はすべてオリジナルです。

| 場面 | 曲 |
| --- | --- |
| タイトル | 堂々としたマーチ |
| フィールド（昼） | 軽快に歩きまわる曲 |
| フィールド（17時以降） | 少しさみしげな夕暮れの曲 |
| 建物の中・朝の事務所・出陣式 | のどかな町の曲 |
| 偶然の出来事・朝市などの集会 | 「なにか起きた！」曲 |
| スキャンダル報道・過労で倒れる | 不穏な曲 |
| 夜の報告 | 子守歌 |
| 公開討論会・テレビ討論・最後のお願い | 戦闘曲ふう |
| 開票速報 | 緊張感のある刻み |
| 当選 / 落選 | ファンファーレ / 哀しい曲 |

メニューの「おと」で効果音とBGMをまとめて ON/OFF できます。

## Android 版（Google Play 配布用）

[Capacitor](https://capacitorjs.com/) でゲームのファイルをアプリ内に同梱しているため、ネットにつながっていなくても遊べます（フォントも `css/fonts/` に同梱）。

- 横画面固定・全画面表示（ステータスバー／ナビゲーションバーを隠す）
- プレイ中は画面が暗くならない
- 左に十字ボタン、右に A・B ボタン、真ん中にゲーム画面。横長の画面では見える範囲を横に広げ、文字も画面の高さに合わせて大きくする
  （スマホのブラウザを横向きにしたときも同じ配置。縦向きでは画面の下に操作ボタンを出す）
- Android の戻るボタンは B ボタンと同じ（メニュー・キャンセル）。タイトル画面ではアプリを終了
- 別のアプリに切り替えると音が止まり、その時点の状態を自動でセーブする
- エンディングの「結果を シェアする」は Android の共有メニューから LINE や X などを選べる
- 案内文はタッチ操作のボタン名で表示

アプリ ID は `jp.techgym.kenchiji` です（Google Play に一度公開すると変更できません）。

### 広告（Google AdMob）

Android アプリでのみ広告を表示します（Web 版には広告は出ません）。

| 広告 | タイミング |
| --- | --- |
| インタースティシャル（全画面） | 毎晩、夜の報告を閉じたあと（1〜17 日目） |
| リワード | 過労で倒れたときに「応援動画を見て立ちあがる」を選ぶと、体力 60 で その日の活動を続けられる（1 日 1 回） |
| リワード | 選挙事務所の「応援動画を見る」で体力が全回復（1 日 1 回） |
| バナー（画面の下） | 起動してからずっと表示（タイトル・プレイ中・メニュー・結果画面）。ゲーム画面はバナーのぶん上に詰めて、操作ボタンと重ならないようにする |

- EU・英国など同意が必要な地域では、初回起動時に Google の同意確認画面が出ます。その地域では、タイトル画面の「広告の設定」から同意内容をいつでも変更できます。
- プライバシーポリシー（https://techgym.jp/privacy-policy/ ）へのリンクをタイトル画面に表示しています。
- 広告ユニット ID（インタースティシャル・リワード・バナー）は `js/ads.js` の `production`、AdMob のアプリ ID は `android/app/src/main/res/values/strings.xml` にあります。
- 動作確認用 APK（Release の `kenchiji.apk`）は常に **Google のテスト広告** を表示します。自分でタップしても問題ありません。
- Google Play 用の .aab をビルドするときだけ、CI が `ADMOB_MODE=production` で本番の広告に切り替えます（`scripts/build-web.js` が `js/ads-config.js` を書き換えます）。
- 本番の広告を自分でタップするとアカウント停止の対象になるので注意してください。

### ビルド方法

**GitHub Actions（自動）**: Web 版や `android/` を変更して push すると、`.github/workflows/android.yml` が動作確認用の APK を作ります。
既定ブランチのビルドは GitHub の Release（`android-latest`）に自動で載るので、Android 端末で次の URL を開くか QR コードを読み取るだけで最新版をダウンロードできます。

https://github.com/techgymjp/kenchiji/releases/latest/download/kenchiji.apk

<img src="docs/apk-qr.png" alt="APK ダウンロード用 QR コード" width="180">

リリースページ（バージョンや説明を見てからダウンロードする場合）: https://github.com/techgymjp/kenchiji/releases/tag/android-latest

<img src="docs/release-qr.png" alt="APK リリースページの QR コード" width="180">

ダウンロードした `kenchiji.apk` を開き、「提供元不明のアプリ」のインストールを許可するとインストールできます。
動作確認用の署名鍵（`android/app/debug.keystore`）はリポジトリで固定しているので、新しいビルドもアンインストールせずに上書きインストールできます。
（Release に載る APK はデバッグ版です。Google Play には下の手順で作る署名済み .aab を使います）

**手元の PC（Android Studio）**:

```bash
npm ci
npm run android:sync   # Web ファイルを www/ にまとめて Android プロジェクトへコピー
npm run android:open   # Android Studio で開く
```

### Google Play へ公開する手順

1. アップロード鍵（`upload.jks`）は他のゲームと同じものを使い回せます。新しく作る場合は次のとおり（Java が必要）
   ```bash
   keytool -genkeypair -v -keystore upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
   base64 -i upload.jks | tr -d '\n' | pbcopy          # macOS（クリップボードにコピー）
   ```
2. GitHub のリポジトリの Settings → Secrets and variables → Actions に次の 4 つを登録する
   | 名前 | 内容 |
   | --- | --- |
   | `ANDROID_KEYSTORE_BASE64` | `upload.jks` を base64 にした文字列 |
   | `ANDROID_KEYSTORE_PASSWORD` | キーストアのパスワード |
   | `ANDROID_KEY_ALIAS` | `upload`（作成時に指定した別名） |
   | `ANDROID_KEY_PASSWORD` | 鍵のパスワード |
3. Actions の「Android build」を実行すると、署名済みの `kenchiji-release-aab`（.aab）ができる
4. [Google Play Console](https://play.google.com/console) でアプリを作成し、.aab をアップロードする
   （ストア掲載情報・スクリーンショット・プライバシーポリシー・コンテンツのレーティングなどの入力が必要です。
   広告を入れているので「広告を含む」の申告、データセーフティでの広告 ID の申告も必要です）

バージョン番号（versionCode）は Actions の実行回数が自動で使われます。表示用のバージョン名は `package.json` の `version` で、タイトル画面の右下に表示されます。

## Web 版の公開（Vercel）

## ファイル構成

```
index.html
css/style.css
js/sprites.js   ドット絵（キャラ・タイル）の生成
js/map.js       マップ・地区・建物・NPC
js/ui.js        メッセージ／選択肢ウィンドウ・入力・効果音
js/bgm.js       ファミコン風BGM（曲データとシーケンサー）
js/events.js    団体・演説・ランダムイベント・遅延イベント・予定イベント・施設
js/election.js  支持率モデル・世論調査・開票速報・エンディング
js/engine.js    ゲーム状態・移動・描画・1日の流れ・タイトル
js/i18n.js      表示言語の切り替えと、画面の固定文言（日本語 / 英語）
js/i18n-en.js   英語の翻訳表（日本語の文 → 英語の文）
js/native.js    Android アプリとの連携（戻るボタン・アプリ切替・シェア・バージョン表示）
js/ads.js       Google AdMob 広告（Android アプリのみ）
js/ads-config.js  広告のモード（test / production。ビルド時に生成）
js/build-info.js  タイトル画面に出すバージョン（ビルド時に生成）
css/fonts/      DotGothic16 フォント（SIL OFL 1.1）
assets/         アイコンと起動画面の元画像
android/        Android アプリのプロジェクト（Capacitor）
scripts/        www/ にまとめるビルドスクリプトと、英語の訳もれチェック（check-i18n.js）
docs/           APK ダウンロード用・リリースページ用の QR コード、ストア用アイコン
```

セーブは毎朝自動で行われ、ブラウザの localStorage に保存されます（メニューから手動セーブも可能）。
メニューの「タイトルに もどる」を選ぶと、セーブしてからタイトル画面に戻ります（「つづきから」で同じところから再開）。
